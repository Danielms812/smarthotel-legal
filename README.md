# smartbed-legal

Página de política de privacidad para la app **Smart Hotels**, publicada vía GitHub Pages.

## URLs una vez publicado

| Idioma | URL |
|--------|-----|
| Español | `https://danielms812.github.io/smartbed-legal/` |
| English | `https://danielms812.github.io/smartbed-legal/privacy-en.html` |

## Cómo publicar

1. Crea un nuevo repositorio en GitHub llamado **`smartbed-legal`** (público).
2. Copia los dos archivos HTML a la raíz del repo:
   - `index.html`
   - `privacy-en.html`
3. Ve a **Settings → Pages → Branch: `main` / root (`/`)** y guarda.
4. En pocos segundos la página estará disponible en la URL de arriba.

## Dónde añadir la URL en App Store Connect / TestFlight

- **App Store Connect → Mi app → Información de la app → URL de política de privacidad**  
  → `https://danielms812.github.io/smartbed-legal/`

Apple requiere que esta URL sea accesible públicamente antes de aprobar la revisión.
