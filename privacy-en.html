Privacy Policy

Smart Hotels — Last updated: April 21, 2026

1. Introduction

Smart Hotels is a mobile application developed by Daniel Martínez Salinas (Nexo Technologies) that enables hotel staff to intelligently control motorized smart beds via Bluetooth Low Energy (BLE) and local-network communication with a control hub.

This privacy policy describes how the application handles user information. We are committed to protecting your privacy and being transparent about data practices.

2. Data We Collect

Smart Hotels is designed with an offline-first approach. Day-to-day operation requires no Internet connection and does not actively collect personal data. Specifically:

  • No personal user accounts are created.
  • No personally identifiable information is collected (name, email, phone number, etc.).
  • No analytics or advertising services are used.
  • No user-behaviour tracking is performed.

The only interaction with an external service is the delivery of push notifications via Firebase Cloud Messaging (Google), described in section 5.

3. Information Stored Locally

The application stores the following information exclusively on your device:

  • Hub configuration: the IP address and access credentials for the local control hub (Raspberry Pi), stored in encrypted form using the operating system's secure storage.
  • Paired bed identifiers: the Bluetooth MAC address of each managed bed.
  • Application preferences: interface settings and usage configuration stored locally.

This data is stored only on the device and is never sent to any external server. Uninstalling the application automatically deletes all this data.

4. Device Permissions

Smart Hotels requests the following permissions:

🔵 Bluetooth
Required to scan for and connect to smart beds. Communication is direct between the device and the bed (BLE), with no external intermediaries. It is not used to track the user's location.
📍 Location
On Android, the operating system requires the location permission in order to perform Bluetooth scans. The application does not use or store the user's geographic location. On iOS, BLE proximity is used solely to detect nearby beds.
🎤 Microphone and Speech Recognition
Used exclusively for the voice command feature ("raise", "lower", "stop"). Recognition is performed locally on the device. No audio is recorded or transmitted to external servers.
🌐 Local Network and Internet
The app requires access to the local network (Wi-Fi) to communicate with the bed control hub (Raspberry Pi). Internet connectivity is used solely for delivering push notifications via Firebase and, in future versions, for hotel-cloud synchronisation.
🔔 Notifications
The app may receive push notifications sent by the hotel hub (e.g., bed status alerts). Explicit permission is requested before activating them.

5. Third-Party Services

Smart Hotels uses the following third-party service:

Google / Firebase Firebase Cloud Messaging (FCM) — Used to deliver push notifications to the device. To do so, Google registers a device token (an anonymous identifier) on its servers. No personal data is sent. Google's privacy policy: policies.google.com/privacy .

The application does not contain advertising SDKs, third-party analytics, or social media SDKs.

6. Security

We take measures to protect the information managed by the application:

  • Hub credentials are stored encrypted using the operating system's secure storage (Keychain on iOS, Keystore on Android).
  • Bluetooth communication uses the standard BLE security mechanisms of the protocol.
  • Communication with the hub on the local network can be configured with authentication.
  • No personal data is collected or transmitted to external servers, minimising exposure risks.

7. Children's Privacy

Smart Hotels is a professional application intended for hotel staff. It is not directed at children under 16 and does not knowingly collect information from minors. The application controls motorised equipment and must be used by authorised adult personnel only.

8. Changes to This Policy

We may update this privacy policy from time to time. We will notify you of any changes by posting the new policy on this page with the corresponding update date. Continued use of the application after changes are published constitutes acceptance of the updated policy.
